# Leonardo Canazart, Portfólio

Site pessoal e portfólio técnico de Leonardo Canazart, graduando em Engenharia de Minas pela Universidade do Estado de Minas Gerais (9º período) e Técnico de Sala de Controle I na Bemisa (Mina Pedra Branca).

## Conteúdo

- Trajetória profissional: Bemisa, ArcelorMittal Brasil, PH Intralogística e Construtora Helmo.
- Estudos de caso: Validação Heurística e Auditoria de Frota (Custom BRE), Short Interval Control (SIC) com integração via API e análise histórica de produção em mina com Python (KDD) e estudos em Machine Learning.
- Demonstrações interativas no navegador: motor BRE (regras R0 a R7 com planilha editável) e simulador horário do SIC.
- Formação acadêmica, certificações e ferramentas.
